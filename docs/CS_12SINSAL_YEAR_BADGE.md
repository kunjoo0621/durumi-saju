# CS 대응 문안 — 결과 화면 년주 12신살 배지 변경 문의

작성: 2026-08-03 · 근거: docs/SAJU_FACT_INTEGRITY_PLAN.md §8③ (무고지 채택 시 필수 조건)

## 배경 (내부용 — 사용자에게 그대로 보내지 않음)

- 12신살 산출에서 년주만 일지 삼합 기준으로 잡던 비표준 방식을 사전 조견표와 같은
  **년지(年支) 기준**으로 통일했다 (`lib/utils/saju-enrichment.ts` `getPillar12Shinsal`).
- 배지는 저장값이 아니라 **렌더 시 계산**이라 기존 유료 결과 화면에서도 년주 배지가 배포
  즉시 바뀌어 보인다. 기존 결과의 약 74.9%가 해당하며, 변경 방향은 흉→비흉이 약 3:1.
- 개인 분석 **점수·등급 산식은 `pillar12Shinsal`을 사용하지 않는다** — 등급·점수 불변은
  사실 확인된 내용이다(임의로 범위를 넓혀 답하지 말 것).
- 운영자 결정: 개별 고지 없음. 문의 인입 시에만 아래 문안으로 대응.

## 사용자 문의 예상 유형

"예전에 본 결과에서는 년주가 겁살(또는 다른 살)이었는데 지금 보니 바뀌어 있어요."
"스크린샷이랑 지금 화면이 달라요. 결과가 조작된 건가요?"

## 대응 문안 (그대로 사용)

> 안녕하세요, 두루미사주입니다.
>
> 말씀하신 부분은 12신살 중 **년주(년기둥) 표기 기준을 정비**하면서 달라진 것이 맞습니다.
> 12신살은 전통 명리에서 태어난 해의 지지(년지)를 기준으로 네 기둥에 별을 붙이는
> 체계인데, 이전에는 년주 한 칸에 다른 기준이 섞여 표기되는 문제가 있어
> 저희 사주사전의 12신살 조견표와 같은 **년지 기준으로 통일**했습니다.
>
> 이번 정비는 12신살 배지 표기에만 해당하며, **분석 결과의 등급·점수·본문 풀이에는
> 영향이 없습니다.** 12신살 배지는 저장된 값이 아니라 열람 시점에 계산되어 표시되기
> 때문에, 이전에 받으신 결과 화면에서도 정비된 기준으로 보이게 됩니다.
>
> 혼란을 드려 죄송합니다. 추가로 궁금하신 점이 있으면 언제든 문의 주세요.

## 대응 시 주의

- "버그였다/오류였다"는 표현 대신 "기준 정비/통일"로 답한다 (사실관계: 표준 조견표와의
  일치화이며, 명리적으로 년지 기준이 정통).
- 등급·점수 재산정, 재분석, 환불 약속을 임의로 하지 않는다 — 점수는 실제로 변하지 않았다.
- 문의가 반복 인입되어 임계치를 넘으면 운영자에게 보고 (개별 대응 → 공지 전환 여부는
  운영자 결정 사항).
