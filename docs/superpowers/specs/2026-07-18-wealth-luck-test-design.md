- 작성일: 2026-07-18
- 상태: 승인됨 (재물 특화 결정 확정)

## 1. 목적과 포지셔닝

개인사주 result의 "재물운 점수 + 코어피어(돈·재정)" 요약 **뒤의 이유**를, **동일한 원국을 확대**해 재물 영역만 심층으로 판다. 결혼운과 동일 논리.

### 차별화 (결혼운과 같은 하드 규칙)
- 개인사주가 이미 말한 재물운 요약 **반복 금지** + 반드시 **한 단계 아래 해상도**(어느 기둥·지장간·몇 년).
- 고유 값어치 3축: ①**재성 구조 진단**(정재/편재) ②**재를 감당하는 그릇**(신강신약×재) ③**시기론**(입재/손재 타이밍).
- 투자 스킬(durumi-money)과 다름: 이건 *사주 콘텐츠*지 재무자문·종목추천 아님.

## 2. 입력 (재물 관심사 4분법 — 신규 질문)

- primary 사주 재사용 (`from-primary`).
- **신규 적응 질문 "지금 재물 관심사" 4분법**: `목돈 모으기 / 투자로 불리기 / 사업·수입 키우기 / 지출·빚 관리`
  - 결혼운의 성별 분기 없음 — 재성은 남녀 공통.
  - employment_status 프리필 대신 **재물 전용 질문을 새로 받음**(운영자 결정). 저장 안 함(검사 내부 4분법). 원탭 선택.
  - 관심사 → 명리 앵글 매핑: 목돈=정재·재고(안정 축적) / 투자=편재·식상생재(리스크·타이밍) / 사업=식상생재·확장·군겁쟁재 / 지출관리=비겁 손재·기신 시기 관리.

## 3. 엔진 모듈 `lib/wealth-facts.ts` (결정론, 기존 프리미티브 조합)

`deriveWealthFacts(enriched, fortune, sajuData, interest, currentYear) → WealthFacts`. `lib/marriage-facts.ts` 구조 미러.

산출:
1. **재성**(정재/편재) 위치·강약 — 정재=안정·월급형, 편재=큰돈·사업·유동형. 기둥별 탐지(천간+지장간). `getTenStar`로 판별(정재/편재 = 일간이 극하는 오행).
2. **재를 감당하는 그릇** — `judgeStrength`(신강신약) × 재성량:
   - 신강 + 재 → 재를 감당(그릇 큼)
   - **재다신약**(신약 + 재 과다) → 돈이 새거나 관리 스트레스 (숙명론 금지, "그릇 관리법"으로)
3. **식상생재** — 식신/상관 존재 → 재 생성 파이프라인(벌이 능력).
4. **군겁쟁재** — 비견/겁재 과다 + 재성 약 → 손재·경쟁·동업 리스크.
5. **재고(財庫)** — 辰戌丑未 중 일간 기준 재의 墓지 유무(재물 창고), 개고 여부. (엔진에 12운성/지장간 있으니 파생 가능; 없으면 보수적으로 생략하고 로그)
6. **용신이 재/식상인지** — `determineYongshin` 결과가 재/식상이면 재물 유리 신호.
7. **타이밍 트리거** 연도 리스트: (a) 세운/대운에 **재성 투출**(입재) (b) **식상 투출**(생재) (c) **비겁 강한 시기**(손재 주의). `fortune.seun`/`daeun.pillars`의 tenStar로 판정.
8. **재물 성향 요약** — 정재우세=안정형 / 편재우세=승부형 / 식상생재=자수성가형 / 무재=월급·전문직형(무재를 "돈복 없다"로 직행 금지).

### 신살 정책
- 재물 관련 길신(예: 천을귀인 등)은 엔진 검증값만. 근거 얇은 흉살·공포성 신살 노출 금지(결혼운과 동일 금지 리스트 계승).

## 4. 리포트 블록 (엔진 재료의 조합 해석만 LLM)

### 공통 코어
1. **재물운 등급** — SS~C. **재물운 점수 → 등급 밴드 서버 결정론 매핑**(LLM 재량 금지; `computeMarriageGrade` 로직 재사용 = `computeWealthGrade`).
2. **재성 진단** — 정재/편재·강약·위치·식상생재 유무.
3. **재를 담는 그릇** — 신강신약×재, 재다신약이면 관리 관점으로.

### 관심사별 강조 (4분법)
- **목돈 모으기**: 축적 방식(정재·재고), 저축형 vs 투자형 성향, 그릇 키우는 법.
- **투자로 불리기**: 편재·식상생재 성향, 리스크 감내, 투자/회수 타이밍 vs 조심할 시기.
- **사업·수입 키우기**: 식상생재 확장력, 군겁쟁재·동업 리스크, 확장 타이밍.
- **지출·빚 관리**: 손재 패턴(비겁·기신 시기), 새는 지점, 통제·관리법.

### 공통 마무리
4. **실천 조언** — 각 항목 **`[근거:...]` 태그 필수**(없으면 후처리 컷). "돈 아끼세요" 류 금지, 진단 근거에 결선.
5. **CTA** — **올해의 운세(yearly)**: "올해 재물 흐름을 월별로" 연결 (심층 원국 → 시기 흐름 자연 연결).

## 6. 하드 규칙 (quality-gate / postprocess 강제)

### 차별화 / 일관성 (결혼운과 동일)
- 개인사주 반복 금지 + 한 단계 아래 해상도.
- 등급 = 재물운 점수 결정론 매핑. 성별·재성 등 원국 파생값을 메인 result와 대조(`assertWealthConsistency`).

### 재물 안전장치 (여명 안전장치의 재물 버전)
1. **숙명론·공포·서열화 금지**: "가난할 팔자 / 평생 돈 못 번다 / 거지 사주 / 돈복 없다" 절대 금지. 구조는 '경향 + 방식 + 노력'으로만.
2. **재다신약 재해석**: "돈복 없다" 직행 금지 → "버는 힘보다 담는 그릇·관리가 관건인 구조"로 번역.
3. **투자 손실 단정 예언 금지**: 특정 시기 "반드시 손해" 금지 → 경향+관리(조심할 시기 = 대응법 세트).
4. **재무자문 아님**: 특정 종목·투자 상품 권유 금지. 명리 성향·시기 해석까지만. (durumi-money 투자 스킬과 분리)
5. **무재(無財) 처리**: "돈복 없음" 금지 → 월급·전문직·식상 활용 등 대체 경로 + 대운 입재 시기로.

## 10. Fable 검증 반영 (v2, 2026-07-18) — 착수 전 필수

Fable가 코드 실측 + 1,000명 몬테카를로로 확인한 치명 결함. **v1 엔진(Task1)은 되돌리고 아래를 반영해야 품질바 통과.**

### 실측 발화율 (v1 엔진, 재설계 목표치)
- 식상생재 94.7%(변별력0) / 재다신약 41.7%(낙인) / 그릇 강·중·약 47·11·42('중' 사망) / 그릇강∧군겁쟁재 12.2%(모순) / 군겁쟁재 무재 발화(오류).

### 엔진 v2 재설계 (가중 모델)
- **재성·비겁 강약 가중**: 천간투출 3 / 지지정기 2 / 중기 1 / 여기 0.5 + 월지 가중. (v1의 지장간 무가중 전수카운트 폐기)
- **재다신약** = 신약 ∧ 가중재성 상위임계 (목표 발화 ~10-15%).
- **군겁쟁재** = 비겁왕 ∧ 재성 존재하되 약 ∧ **관성 구제 없음** (**무재 제외**).
- **그릇** = 신강신약 × 가중재성강약 **2차원 4상한**(신왕재왕/신왕재쇠/재다신약/신약재소) + **"그릇강 ∧ 군겁쟁재 동시 발화 금지"** 상호배타.
- **비겁 타이밍 라벨 반전**: 신약이면 "비겁손재"가 아니라 **"조력(용비겁) 시기"** — 리포 용신 모듈과의 자기모순 제거.
- **개고 미구현** → 프롬프트에 "개고 언급 금지"(fabrication 방지). 재고는 보조신호 이상 팔지 않음(단독 '창고=축적유리' 서사 금지).
- **재설계 후 몬테카를로 재검증**(시드 고정 스크립트, 발화율 목표 확인).

### 재탕 방지 — 타이밍 주력
- 개인사주 재물운 점수가 이미 정재/편재/식상생재/신강/비겁으로 구성 → 헤드라인 개념이 재탕. **고유 자산 = 타이밍(세운/대운 연도)**. 리포트 무게중심을 타이밍·구조해상도에 둔다.
- **재성 강약(통근·득령·투출)** 을 반드시 산출(스펙 §3-1 "위치·강약" 약속 이행). 위치만으론 값어치 부족.
- **메인 result 십성표 불일치 주의**: 메인 `calculateTenStars`는 지지 정기만 셈. 심층이 "재성혼재"인데 메인엔 재성 없으면 눈에 보이는 모순 → `assertWealthConsistency`가 이것도 대조(가중 재성 유무 vs 메인 정기 십성).

### 입력 보강
- "목돈 모으기" → **"목돈·노후 준비"**로 확장 (35-54 여성 최대 관심사=노후, 4분법 유지).
- primary `employment_status`를 **프롬프트 grounding으로 조인**(관심사는 새 질문으로 받되, 사업자에 월급조언/주부에 승진조언 사고 방지).
- **관심사-구조 불일치 하드 규칙**: 편재우세인데 "목돈 모으기" 선택 등 → "원하는 방식 vs 타고난 구조"의 간극을 짚는 게 가장 비싼 문장. 프롬프트 필수 룰.

### 안전 강화
- **재무자문 아님 = 결과표 하단 결정론 하드코딩 푸터**("본 리포트는 명리 해석 콘텐츠이며 투자 자문이 아닙니다"). LLM/스크럽에 안 맡김(법적 선긋기=확률장치 금지).
- **타이밍 전부 "점검·관리·기회를 살필 시기" 프레임 강제** — 손실뿐 아니라 **이익 단정도 금지**(입재 시기 믿고 투자→손실 = 더 큰 신뢰 리스크).
- Task 9 critic 케이스에 **C등급 + 무재** 최악 케이스 추가.

### 등급 앵커 — ver18 선행 (운영자 결정 2026-07-18)
- 등급이 확정버그 위에 있음: `hasBigyeobOverload`(saju-scoring.ts:183)가 dedup Set 탓에 영원히 false → 비겁 감점 죽음 → 비겁과다 코호트 재물운 점수 부풀림 → "A등급 + 군겁쟁재 손재경고" 부조화(타깃층에서 발생).
- **운영자 결정: ver18 스코어링 픽스를 재물운 출시 전에 먼저 확정** ([[project_durumi_scoring_bugs]]). 그 후 재물운 등급 매핑이 정확한 앵커 위에 서게 됨.
- 착수 순서: **ver18 → 엔진 v2 → 나머지 빌드**.
