**Goal:** 현재 "미니멀 단색 배경 + 소품 1개"로 절제된 관계 일러스트를, 아키타입별 **테마 있는 세계관**(테마 배경 + 소품 3~5개 + 연출)으로 화려하고 다양하게 격상한다. 단 정체성(사진 속 그 아이) > 펫 주인공 > 장면 > 스타일의 우선순위와 보호자 손-only·두루미 다크 톤·1:1·텍스트 금지·2단 fallback은 전부 유지한다.

## 1. 컨셉 방향 — "테마 세계관"과 4대 원칙의 양립

### 접근

각 아키타입을 **하나의 작은 세계관**(무대)으로 정의한다: 테마 배경 1개 + 관계 은유를 강화하는 소품 3~5개 + 보호자 손의 역할 + 펫 포즈·표정. 화려함은 "물량"이 아니라 **은유의 밀도**에서 나온다 — 소품은 예쁘라고 넣는 게 아니라 전부 "누가 상전인지/누가 매달리는지"를 한 번 더 말해주는 것만 넣는다.

### 양립 장치 (충돌 지점별)

| 원칙 | 위협 | 장치 (프롬프트에 명문화) |
|---|---|---|
| ① 정체성 최우선 | 화려한 배경이 모델의 주의를 뺏어 털색·무늬가 뭉개짐 | 정체성 블록을 계속 맨 앞 + "배경·소품이 아무리 화려해도 아이의 털색·무늬·생김 디테일이 항상 우선, 배경 디테일과 아이 디테일이 경쟁하면 아이가 이긴다" 명시 |
| ② 펫이 주인공 | 궁전·선물더미에 펫이 파묻힘 | (a) 펫 화면 55~75% 유지(궁전 등 와이드 씬 위해 하한만 60→55 완화) (b) **얕은 피사계심도** — 배경은 부드럽게 블러/보케 (c) **명도·채도 위계** — 화면에서 가장 밝고 선명한 것은 항상 아이, 배경은 아이보다 어둡고 덜 선명 (d) 림라이트로 아이 실루엣 분리 |
| ③ 보호자 손-only | 시종·집사 연출에서 사람 몸이 등장 | OWNER_CONSTRAINT의 얼굴·몸통·전신 금지 문구 그대로 유지, 씬마다 손의 "배역"만 지정 (시종 손·구애 손·집사 손) |
| ④ 두루미 다크 톤 | 테마 컬러가 파스텔·원색으로 튀어 싸구려/유치 | **다크 시네마틱 베이스 + 아키타입 악센트** 방식 — 베이스는 지금처럼 어두운 진회/진녹 무드를 유지하되, 아키타입별 악센트 컬러 1~2개(옥좌의 금·버건디, 노을의 앰버 등)만 얹는다. 전체 톤을 아키타입별로 풀어버리는 방식은 **기각**: 결과 hero(1:1) 그리드·공유 이미지에서 서비스 룩이 흩어지고, 밝은 톤은 싸구려로 빠지기 쉬움 |
| ⑤ hero에서 작게도 읽힘 | 소품이 많아지면 썸네일에서 노이즈 | "구도는 한 문장 — 멀리서 봐도 [관계 한 줄]이 읽히는 단순한 큰 실루엣, 소품은 그 문장을 꾸미는 조연" + 소품이 아이 얼굴을 가리지 않게 |

### "미니멀 배경·소품 1개" 제약 개정 방향

- **삭제**: "미니멀한 단색/그라데이션 배경", "소품은 한 개까지만"
- **대체**: "아키타입 테마 배경 허용 (다크 시네마틱 베이스 + 악센트), 소품 3~5개 — 단 전부 관계 은유를 강화하는 것만, 배경은 피사계심도로 뒤로"
- 소품 수 규칙은 OWNER_CONSTRAINT에서 빼서 각 SCENE_BLOCK이 소유 (씬마다 필수 소품·선택 소품이 다르므로)

## 2. 아키타입 8종 × 테마 세계관 설계

각 항목: (a) 테마 배경 / (b) 소품 3~5개 = **필수 1~2 + 선택 풀** / (c) 보호자 손·무릎의 배역 / (d) 펫 포즈·표정. 라벨(타이틀) 결은 pet-compat-scoring.ts의 분기 텍스트와 일치.

### PET_THRONE — 「간식 셔틀과 네 발 상전」 · 로열 팰리스 (운영자 예시)
- (a) 어둑한 왕궁 알현실 — 벨벳 커튼, 은은한 샹들리에 보케, 금·버건디 악센트
- (b) 필수: **머리 위 작은 황금 왕관(살짝 삐딱하게)** + 벨벳 옥좌(또는 옥좌급 캐노피 방석). 선택 풀: 붉은 카펫, 간식이 쌓인 은쟁반, 방석 계단, 금술 쿠션
- (c) 손 = **시종**: 화면 아래 가장자리에서 두 손이 은쟁반/간식 그릇을 공손히 받쳐 올림
- (d) 옥좌에 여유롭게 앉아 턱을 살짝 들고 아래를 내려다보는 근엄+귀여운 표정. 로우앵글(아래에서 올려다보는 카메라)로 위엄 과장

### OWNER_DEVOTION — 「짝사랑·더 빠진 쪽은 너」 · 스포트라이트 구애 무대
- (a) 어두운 방/무대에 펫에게만 쏟아지는 스포트라이트, 주변은 어둠에 잠김
- (b) 필수: **리본 선물 상자 더미** + 손에 든 구애 아이템(간식·장미 한 송이). 선택 풀: 간식 탑, 꽃다발, 하트 풍선, 손 주변에만 떠 있는 작은 하트들
- (c) 손 = **구애자**: 가장자리에서 선물/간식을 간절히 내밀지만 받아들여지지 않는 중
- (d) 스포트라이트 한가운데서 시크하게 고개를 살짝 돌림 — 단, 곁눈질로 은근히 의식 (도도함이 포인트, 차갑지 않게)

### PET_DEVOTION — 「너에게 올인한 순정파·껌딱지」 · 현관 앞 해바라기
- (a) 골든아워 빛이 스며드는 현관/복도 — 앰버 악센트, 따뜻한 어스름
- (b) 필수: **입에 물거나 앞발로 끌어안은 산책줄(또는 보호자 물건)**. 선택 풀: 현관 러그, 보호자 슬리퍼 한 켤레, 아이 주변에 떠오르는 하트, 문틈으로 새어드는 빛줄기
- (c) 손 = **돌아온 사람**: 가장자리에서 손바닥을 내밀고, 아이가 거기에 뺨·앞발을 부빔
- (d) 온몸으로 반기는 애틋한 올려다봄 — 꼬리 흔들림/몸 기울기까지 크게

### HARMONY — 「전생에 한 이불·환상의 복식조」 · 포근한 저녁 거실
- (a) 스탠드 조명·벽난로 불빛의 아늑한 저녁 거실, 진회 베이스 + 웜 오렌지 악센트
- (b) 필수: **같은 패턴의 커플 아이템**(담요+쿠션, 머그+물그릇 나란히). 선택 풀: 창밖 달·별, 폴라로이드 액자(사진은 실루엣만·글자 없음), 김 나는 머그, 소파 위 니트
- (c) 손 = **단짝**: 아이 등을 감싸거나 나란히 놓여 같은 곳을 봄
- (d) 손에 편안히 기대 눈웃음, 둘이 같은 방향을 보는 안정 구도

### OWNER_MANAGER — 「이 집 결재권자는 너(보호자)」 · 프리미엄 그루밍 살롱
- (a) 정갈하게 정돈된 살롱/스파 코너 — 진녹 베이스, 차분한 골드 악센트, 모든 것이 각 잡혀 있는 무드
- (b) 필수: **브러시 + 가지런히 개켜진 수건 타워**. 선택 풀: 리본/빗 정렬 선반, 세면 그릇, 은은한 스팀, 발 매트
- (c) 손 = **유능한 집사/관리자**: 브러시로 아이를 정성껏 정돈
- (d) 얌전히 눈을 지그시 감고 관리받는 호강 표정 — "관리당하는 게 싫지 않음"

### OFFBEAT — 「투닥·유난·삐짐」 · 방치된 장난감 산의 삐짐 현장
- (a) 놀이 코너의 저녁 — 어질러진 흔적이 귀엽게 보이는 웜 라이트
- (b) 필수: **등 뒤에 쌓인 손도 안 댄 장난감 산**(공·오리 인형·깃털 막대). 선택 풀: 넘어진 간식통, 반쯤 뜯다 만 장난감 포장, 아이 머리 위 만화식 뾰로통 구름(과하면 제외)
- (c) 손 = **화해 시도자**: 장난감 하나를 들고 조심스레 내미는 중
- (d) 등을 살짝 돌린 새침·뾰로통 표정, 그러나 **꼬리와 귀는 손 쪽을 향함** — 험악 금지, 사랑스러운 삐짐

### ROOMMATE — 「츤데레 룸메이트·한 지붕 아래」 · 반반 나눠 쓰는 방
- (a) 화면이 좌우 두 존으로 은근히 나뉜 방 — 펫 존(캣타워/쿠션)과 사람 존(책상 모서리), 러그가 경계
- (b) 필수: **각자 영역의 살림**(펫 쪽 쿠션·장난감 vs 사람 쪽 머그·책 — 책 표지 글자 없음). 선택 풀: 스탠드 불빛, 경계 러그, 각자 간식
- (c) 손·무릎 = **동거인**: 자기 존 가장자리에서 머그를 들거나 무릎만 걸침
- (d) 자기 자리에서 무심한 척, 시선만 슬쩍 손 쪽 곁눈질 — 츤데레

### DISTANT_FATE — 「천천히 스며드는 인연·묘연」 · 노을 창가
- (a) 큰 창으로 노을이 길게 스며드는 방 — 앰버·라일락 노을 악센트, 바닥에 길게 뻗은 빛
- (b) 필수: **창턱의 새싹 화분**(스며드는 인연의 은유) + 바닥의 긴 노을 빛줄기. 선택 풀: 창밖 노을 구름, 아직 안 쓴 새 방석, 손이 놓아둔 간식 하나
- (c) 손 = **천천히 다가가는 사람**: 가장자리에서 간식을 조심스레 놓아두거나 반쯤 내밈
- (d) 조금 떨어져 있지만 손 쪽을 가만히 바라보는 호기심 어린 눈 — **단절감·쓸쓸함 금지, 희망적·애틋하게** (현행 톤 가드 유지)

## 3. 다양성 장치 — 같은 아키타입도 매번 다르게

프롬프트가 정적 문자열이라 그대로면 같은 아키타입은 늘 같은 그림이 된다. 2단으로 해결:

1. **프롬프트 내 변주 (기본, 코드 0줄)** — 각 SCENE_BLOCK을 "필수 소품 1~2 + 선택 소품 풀"로 쓰고, "선택 소품 풀에서 2~3개를 **자유롭게 골라** 매번 다른 조합으로" + "카메라 앵글(로우앵글/아이레벨/살짝 하이앵글)과 조명 방향은 자유롭게 변주"를 명시. 모델의 temperature가 자연 변주를 만든다.
2. **코드 변주 (선택, 몇 줄)** — 시간대(저녁/밤/골든아워)·앵글 배열에서 서버가 랜덤 1개를 뽑아 문장에 주입. 1로 부족하다고 실측에서 판단될 때만 추가 (T3, 옵션).

**불변 규칙**: 아키타입의 핵심 은유(왕관+옥좌, 선물더미+스포트라이트, 장난감 산+등돌림, 노을 창가+새싹…)와 관계 역학(누가 상전/누가 매달림)은 변주 대상이 아니다 — 타이틀↔그림 일치가 깨지므로.

## 4. 프롬프트 변경안

### 4-1. OWNER_CONSTRAINT 개정 문구 (초안)

```
보호자는 얼굴·몸통·전신을 절대 그리지 않는다 — 화면 가장자리에서 들어오는
손(또는 무릎)만, 아이와 똑같은 3D 스타일의 단순하고 둥근 손으로.
아이가 화면의 55~75%를 차지하는 단 하나의 주인공이다: 화면에서 가장 밝고
가장 선명하고 가장 초점이 맞은 존재는 항상 아이여야 하며, 어떤 소품도
아이의 얼굴을 가리면 안 된다.
```
변경점: "소품은 한 개까지만" 삭제(소품 규칙은 씬 블록으로 이관), 60~75% → 55~75%(와이드 테마 씬 여유), 초점·명도 주인공 규칙 신설.

### 4-2. [스타일] 블록 개정 문구 (초안)

```
[스타일]
- 픽사풍 소프트 3D 렌더, 통통하고 귀여운 비율, 부드러운 벨벳 같은 털 질감,
  입체감 있는 라이팅과 또렷한 림라이트, 큰 반짝이는 눈
- 배경은 위 장면의 테마 세계관을 풍성하게 — 단 어두운 시네마틱 무드
  (진회/진녹 베이스)를 유지하고, 장면이 지정한 악센트 컬러 1~2가지만 얹는다.
  파스텔 톤·형광색·대낮의 쨍한 밝은 배경 금지
- 얕은 피사계심도: 배경과 먼 소품은 부드러운 보케로 흐리고, 아이에게만
  선명한 초점. 배경은 아이보다 어둡고 채도가 낮아야 한다 (아이가 묻히면 실패)
- 소품은 장면 블록이 지정한 것만 3~5개, 전부 관계를 설명하는 조연으로.
  멀리서 작게 봐도 관계 한 줄이 읽히는 크고 단순한 실루엣 구도
- 정사각형 1:1 비율
- 이미지 안에 텍스트·문자·숫자 절대 금지 — 책·액자·간판·라벨 같은 소품에도
  글자를 그리지 않는다
- 사람 얼굴·전신·실사풍 손 금지
```
변경점: "미니멀한 단색/그라데이션 배경" → 테마 배경 허용 + 다크 베이스·악센트 상한, 피사계심도·명도위계 신설, 소품 3~5개·텍스트 금지를 소품까지 확장(글자 나올 만한 소품 명시).

### 4-3. 우선순위 문구 (초안)

```
우선순위: ① 정체성(사진 속 이 아이의 털색·무늬·생김) > ② 아이가 주인공(초점·크기·밝기)
> ③ 관계 장면·테마 > ④ 스타일. 충돌하면 항상 앞 순위가 이긴다 —
배경이 화려해서 아이의 디테일이 흐려질 것 같으면 배경을 단순하게 후퇴시켜라.
```

### 4-4. SCENE_BLOCKS 8종 재작성 초안

§2의 (a)(b)(c)(d)를 각 3~5문장의 한국어 프롬프트로 옮긴다. 대표 3종 완성 예시 (나머지 5종은 같은 골격으로 구현 시 작성):

**PET_THRONE** (운영자 예시 구현):
```
[테마: 로열 팰리스] 어둑한 왕궁 알현실 — 벨벳 커튼과 은은한 샹들리에 보케,
금색과 버건디 악센트. 아이는 벨벳 옥좌(혹은 옥좌처럼 높고 화려한 방석) 위에
여유롭고 당당하게 앉아 턱을 살짝 들고 아래를 내려다본다. 머리 위에 작은 황금
왕관을 살짝 삐딱하게 씌운다. 화면 아래 가장자리에서 보호자의 두 손이 시종처럼
간식이 담긴 은쟁반을 공손히 받쳐 올린다. 선택 소품(붉은 카펫, 간식 탑,
방석 계단, 금술 쿠션) 중 2~3개를 자유롭게 골라 배치하고, 카메라는 살짝
로우앵글로 아이의 위엄을 귀엽게 과장한다.
```

**OWNER_DEVOTION**:
```
[테마: 스포트라이트 구애 무대] 어두운 방 안, 아이에게만 무대 스포트라이트가
쏟아진다. 화면 가장자리에서 보호자의 손이 간식이나 장미 한 송이를 간절히
내밀고, 손 주변에는 리본 묶인 선물 상자 더미가 쌓여 있다. 아이는 빛 한가운데서
시크하게 고개를 살짝 돌리지만, 곁눈질로는 은근히 손을 의식한다 — 차가움이
아니라 도도한 귀여움. 선택 소품(간식 탑, 꽃다발, 하트 풍선, 손 주변의 작은
하트들) 중 2~3개를 자유롭게 변주한다.
```

**HARMONY**:
```
[테마: 포근한 저녁 거실] 스탠드 조명과 벽난로 불빛이 은은한 저녁 거실.
화면 가장자리에서 들어온 보호자의 손이 아이의 등을 부드럽게 감싸고,
아이는 그 손에 편안히 기대 눈웃음 지으며 손과 같은 방향을 바라본다.
둘 앞에는 같은 패턴의 커플 아이템(담요와 쿠션, 김 나는 머그와 물그릇)이
나란히 놓여 있다. 선택 소품(창밖의 달과 별, 글자 없는 폴라로이드 액자,
소파 위 니트) 중 2~3개를 자유롭게 골라 아늑함을 더한다.
```

나머지 5종(PET_DEVOTION·OWNER_MANAGER·OFFBEAT·ROOMMATE·DISTANT_FATE)은 §2 설계대로 동일 골격(테마 선언 → 필수 소품+관계 역학 → 손의 배역 → 펫 표정 → 선택 소품 풀 변주)으로 작성. DISTANT_FATE는 현행 "단절감·쓸쓸함 금지" 가드 문구를 반드시 유지.

### 검증 절차 (T4)

1. **운영자 승인 게이트** — 유료 Gemini 이미지 생성이므로 실행 전 승인 필수 (feedback_generation_approval). 1차 실측 범위: **PET_THRONE(왕관·운영자 예시), OWNER_DEVOTION, HARMONY** 3종 × 1~2장.
2. **입력 사진** — ★원본 펫 사진은 세션 캐시 만료로 없을 수 있음. 대안: (a) 운영자에게 원본 재업로드 요청(정체성 검증에 최선), (b) 기존 픽사화 이미지 `scratchpad/style-A-pixar.png` 사용(단, 이미 스타일화된 입력이라 **정체성 보존 검증력은 제한적** — 씬·소품·톤 검증용으로만).
3. **실행** — dev 서버에서 `POST /api/pet-compat/dev-illustration` (multipart: photo + name/species/breed + `archetype`). 코드 수정 없이 아키타입 지정 가능(이미 passthrough 확인).
4. **체크리스트** (전 항목 통과해야 나머지 5종 확정):
   - [ ] 정체성: 털색·무늬·품종 특징·표정이 입력과 일치
   - [ ] 주인공: 아이가 최대·최선명·최밝음, 얼굴 안 가려짐
   - [ ] 손-only: 보호자 얼굴·몸통·전신 없음
   - [ ] 테마 읽힘: 그림만 보고 라벨(상전/짝사랑/한이불)이 연상됨
   - [ ] 텍스트 0, 1:1 비율
   - [ ] 200px로 축소해도 관계가 읽힘 (hero 시나리오)
   - [ ] 다크 시네마틱 톤 유지 (파스텔·형광·대낮 밝음 없음)
5. **다양성 확인** — 같은 아키타입 2장 생성 시 소품 조합/앵글이 달라지는지. 안 달라지면 T3(코드 변주) 발동.
