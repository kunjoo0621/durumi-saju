## 1. 벤치마크 매핑표 — 타이트 장치 → 두루미 현황 → 두루미식 번역

| # | 타이트는 X | 두루미는 현재 Y | 두루미식 번역 Z (톤 유지) |
|---|---|---|---|
| 1 | **카드 = 완성된 포스터.** 3:4 세로 full-bleed 일러스트(radius 16, cover), 제목이 아트워크에 박힘, 플로팅 칩("F 접근 금지" 류 장난기) | 메뉴 카드 = 텍스트 + 우측 SVG 도형(일러스트 0). 랜딩 FeatureCard = 텍스트와 이미지가 위아래 분리 | 서비스별 **대표 두루미 일러스트 5종 사전 제작**(§3-1) 후 메뉴·랜딩 카드를 full-bleed 포스터형으로. 단 **제목은 이미지에 굽지 않고 코드 텍스트를 스크림 위에 오버레이** — 시니어 가독성·카피 수정 자유·재생성 비용 0. 칩도 코드 렌더("NEW", "런칭 할인", "츤데레 판정 주의" 류 귀여운 위트) |
| 2 | **섹션 = eyebrow(작은 회색 분야명) + 굵은 훅 제목**("발칙한 연애가 필요하다면?") | 훅 제목(font-aggro 28px)은 이미 있음. eyebrow 계층 없음. 메뉴는 섹션 헤더 자체가 없음 | `SectionHeading` 공용 컴포넌트: eyebrow(13px, text-tertiary) + 훅(font-aggro 22~26px). 훅은 따뜻한 감정형 — "요즘 마음이 복잡하다면?", "우리 아이 속마음이 궁금하다면?" (도발 아님, 공감) |
| 3 | **peek 가로 캐러셀** (카드 폭 86%, 옆 카드 살짝 보임 → 스와이프 유도) | 가로 스크롤 UI 전무. 전부 세로 스택 | **제한 도입.** 핵심 서비스 선택(메뉴)은 세로 스택 유지 — 시니어에게 스와이프는 발견 비용. 캐러셀은 (a) 랜딩 후기, (b) 메뉴 하단 "읽을거리"(매거진 크로스셀)에만 |
| 4 | **소셜프루프** = 방송 제휴(나는솔로)·출연자 인증·🔥별점 리뷰 | `AnalysisCounter`(누적 N명+, 실데이터 기반) 하나뿐. 후기·별점 0 | 제휴 대신 **진정성**: ① AnalysisCounter 유지·확대 배치 ② 결과화면 하단 별점+한줄평 수집 장치(후속, Supabase 자체 테이블) ③ 실후기 쌓이면 랜딩 후기 캐러셀. **가짜 후기·연출 금지** — 쌓이기 전엔 섹션 자체를 안 만든다 |
| 5 | **전환 장치** = 진입 즉시 카카오채널+쿠폰 모달, 니즈별 검색광고 랜딩, 할인 표기 | 스티키 CTA + `ShareRewardBanner` + 펫 런칭 할인(취소선). 진입 모달 없음 | **진입 모달은 안 한다**(두루미 톤에 과함, 시니어에게 닫기 스트레스). 할인·혜택 표기는 카드 칩으로 통일. 니즈별 랜딩은 이미 매거진/사전이 SEO 엔진 — **결과화면→/dict 딥링크(6/1 미완 지적)를 이 기회에 같이**. ★"무료" 주장 절대 금지(가입보너스 종료) |
| 6 | **플로팅 글래스 하단 탭바** | 페이지별 Header + MenuDrawer. 탭바 없음 | **보류.** 서비스 5개·퍼널이 선형(메뉴→입력→결과)이라 탭바 가치 낮음. 스티키 CTA 패턴 유지 |
| 7 | **일관 아트디렉션** (전 상품 한 그림결) | 3결 혼재: 랜딩 이미지 / 메뉴 SVG 도형 / 매거진 cream chibi / 펫 다크 픽사 | **"두루미 서비스 일러스트 v1" 스타일 락 문서** 신설(§3-1). 온사이트(다크 UI 위)는 펫 일러스트 결(다크+웜 라이트 픽사 3D)로 통일, 매거진 hero(cream 에디토리얼)는 별개 결로 존치 — 콘텐츠와 서비스의 결 분리는 의도적 |
| 8 | 다크(#18191A)·Pretendard·핑크레드 포인트 | 다크(#09090B)·Pretendard·rose(#F43F5E) — 이미 동일 구조 | 변경 없음. 토큰 준수만 강화(메뉴 `#141414` 하드코딩 → surface 토큰 정리) |

**포스터형 vs 코드텍스트형 구분 원칙** (★제목을 이미지에 굽는 문제의 답):

| 구역 | 형태 | 이유 |
|---|---|---|
| 랜딩 히어로·서비스 프리뷰, 메뉴 서비스 카드 | **포스터형** (사전 제작 일러스트 full-bleed + 코드 텍스트 오버레이) | 정적·서비스 공통이라 5장만 만들면 됨. 클릭을 판다 |
| 개인 결과화면 (사주·배틀·today·yearly) | **코드텍스트형** 유지 | 내용이 사용자마다 동적 — 굽기 불가. 펫만 예외(관계 일러스트를 이미 실시간 생성) |
| 매거진 카드 | 현행 유지 (hero 이미지 + 코드 제목) | 이미 정답 구조 |

## 2. 개선 영역 우선순위 (임팩트 근거)

| 순위 | 영역 | 근거 |
|---|---|---|
| **P1** | **메뉴 서비스 카드 포스터화** (`app/menu/page.tsx`) | 로그인 후 **모든 세션이 통과하는 허브** = 서비스 선택·크로스셀이 여기서 결정. 현재 5장 전부 SVG 도형이라 진입부 중 시각 판매력이 가장 낮음. 이벤트 실측(one-and-done 94%)상 두 번째 서비스로의 크로스셀이 매출 방향 — 카드가 그 관문 |
| **P2** | **랜딩 개선** (`app/page.tsx`) | 첫인상 + 검색/광고 유입 착지점. eyebrow+훅 계층, 포스터형 서비스 프리뷰(펫·배틀 등 랜딩에 아예 없는 서비스 노출), 소셜프루프 배치 정돈 |

| **P4** | 읽을거리 peek 캐러셀 (메뉴 하단 → /stories) | 매거진은 이미 존재하는 무료 자산인데 본 서비스에서 유입 동선 0. 저비용 크로스셀 |
| **P5** | 공유 화면·OG 이미지 포스터화 | 바이럴 표면이지만 트래픽 절대량이 진입부보다 작음. 후속 |

## 3. 구체 개선안 (두루미 결)

### 3-1. 서비스 대표 일러스트 5종 + 스타일 락 (P1 선행 자산)

- **신규 문서 `docs/SERVICE_POSTER_STYLE.md`** (HERO_ILLUSTRATION_STYLE.md와 동급의 락 문서):
  - 캐릭터: chibi 3D Pixar 두루미(master 결 재사용 — 쇼츠·매거진과 동일 개체)
  - 배경: **다크 네이비/차콜 + 웜 앰버 라이트** — 다크 UI(#09090B) 위에 앉는 결. 매거진 cream 결과 의도적으로 분리
  - 금지: 글자·한자·사람 얼굴·무서운 결 (기존 negative 룰 승계)
  - 소스 비율: **4:5 세로**로 생성(포스터형·가로형 어디에 crop해도 안전한 중앙 구도)
- 장면 5종(칩 카피 후보 포함):

| 서비스 | 장면 | 칩 카피 후보 (귀엽게, 궁금증) |
|---|---|---|
| 개인 사주 | 두루미가 수정구/만세력 두루마리를 들여다보는 서재 | "등급 SS까지 있음" / "돌직구 주의" |
| 궁합 배틀 | 두루미 심판 + 좌우 대결석(귀여운 링) | "5판 승부" / "지면 삐질 수 있음" |
| 오늘운세 | 아침 해 뜨는 창가의 두루미 | "매일 아침 3분" |
| 올해운세 | 사계절이 한 화면에 흐르는 길 위의 두루미 | "터닝포인트 짚어줌" |
| 펫 궁합 | 두루미 + 강아지·고양이 나란히 (펫 일러스트 결과 톤 맞춤) | "NEW" / "런칭 할인" / "우리 아이 편애 주의" |

- **생성은 유료 → 운영자 승인 게이트 필수**(feedback_generation_approval). 프롬프트 초안까지가 계획 범위, 생성 실행 전 승인.
- 저장: `public/images/services/{saju,battle,today,yearly,pet}.png` (+WebP 변환 — serverless 250MB 사고 재발 주의, `outputFileTracingExcludes` 확인).

### 3-2. 메뉴 카드 리디자인 — 2단계 (P1)

**Phase A (저위험, 먼저):** 현행 가로 카드 레이아웃 유지, 우측 SVG 도형 → 대표 일러스트로 교체. 일러스트가 카드 우측을 **bleed로 채우고**(현행 112px 아이콘보다 크게, 카드 높이 꽉), 우→좌 그라디언트로 텍스트 영역과 자연 융합. 텍스트 계층·알 가격·칩은 현행 유지. 카드 bg를 `#141414` → `bg-background-secondary` 토큰으로 정리.

**Phase B (실험, A 검증 후):** 상위 1~2개 카드(사주·펫)를 **full-bleed 포스터형**으로 — 일러스트가 카드 전체(비율 약 16:10), 하단 40% 다크 스크림(`linear-gradient`), 좌하단에 제목(20px+, bold)·설명·가격, 좌상단 플로팅 칩. **시니어 가드: 스크림 위 텍스트 대비 4.5:1 이상 실측, 제목 최소 18px.** A/B 느낌 비교는 전후 스크린샷으로 운영자 판단.

### 3-3. SectionHeading — eyebrow + 훅 (P2)

- 신규 공용 컴포넌트 `components/layout/SectionHeading.tsx`:
  - eyebrow: `text-[13px] text-text-tertiary font-medium` (예: "개인 사주 분야")
  - 훅: `font-aggro text-[24px] leading-[1.3]`
- 랜딩 적용 카피 방향 (따뜻한 감정 훅, 도발 금지):
  - "요즘 마음이 복잡하다면?" → 개인 사주 섹션
  - "그 사람이랑 나, 진짜 맞을까?" → 배틀 섹션
  - "잊을 수 없는 우리 아이라면?" → 펫 섹션 (랜딩에 펫 프리뷰 신설 시)
- 메뉴에도 가벼운 섹션 구분 도입 검토: "지금 볼 수 있는 것" / "읽을거리".

### 3-4. peek 캐러셀 (P4)

- 구현: CSS scroll-snap (`snap-x snap-mandatory`, 카드 `w-[86%] snap-start`, 컨테이너 `overflow-x-auto px-5 -mx-5`). 라이브러리 불필요.
- 적용처: **메뉴 하단 "읽을거리" (StoryCard 축소 변형 or 신규 미니 카드 → /stories)**, 추후 랜딩 후기. 서비스 선택 자체엔 미적용(세로 스택 고수).
- 접근성: 키보드 스크롤 가능, `aria-label`, 스크롤바 숨김은 시각적만.

### 3-5. 소셜프루프 (P2 배치 + P3 수집)

- **지금 가능한 것:** ① AnalysisCounter(실데이터·마일스톤 — 이미 정직한 장치)를 랜딩 히어로 직하로 승격 + 메뉴 상단에도 한 줄. ② 매거진 인기글 조회수 뱃지(StoryCardViewBadge 이미 존재)를 읽을거리 캐러셀에서 그대로 노출.
- **수집 후 가능한 것(후속):** 결과화면 하단 "이 결과 어땠어?" 별점(1~5) + 선택 한줄평 → Supabase 자체 테이블(★PostHog 금지 룰) → 운영자 승인 큐 거쳐 랜딩 후기 캐러셀에 노출. 익명("40대 여성, 사주 이용" 수준)·실후기만.
- **안 하는 것:** 방송 제휴 흉내, 유튜브 구독 수 노출(147은 역효과), 가짜/연출 후기.

### 3-6. 전환 장치 (P2 일부)

- 진입 쿠폰 모달: **도입 안 함.**
- 할인·혜택은 카드 칩으로 통일(펫 취소선 가격 패턴 유지). 카피에 "무료" 계열 표현 전수 금지 — 랜딩 FAQ·칩·CTA 카피 리뷰 시 같이 검수.
- 결과화면 → `/dict` 딥링크(components/result/* — 6/1 미완 지적)를 P2에 편승: 결과가 곧 다음 콘텐츠 랜딩이 되는 구조.
- 카카오 채널 추가 유도: 보류(운영자 결정 사항, 이번 범위 아님).

## 4. 두루미 브랜드 가드 — 절대 안 하는 것

1. **성인·자극·도발** 이미지/카피 전면 금지 (타이트의 "29금·발칙한" 계열 어떤 변형도 X).
2. **공포·서열화 카피 금지** — "F 접근 금지" 같은 배제형 대신 "가능성+노력" 프레임. 등급은 재미 요소로만, 위협 소재로 쓰지 않음.
3. **"무료" 오주장 금지** — 가입보너스 종료(2026-06-21). 칩·CTA·FAQ 어디에도.
4. **시니어 가독성 훼손 금지** — 이미지 위 저대비 텍스트, 12px 미만 본문, 한 카드에 정보 3덩이 초과, 우아하지만 작은 디테일. 스크림+대비 실측 없이 포스터형 출고 금지.
5. **가짜 소셜프루프 금지** — 수치는 실데이터만, 후기는 실후기만.
6. 두루미 캐릭터의 도사화·신비주의 과장 금지(기존 방침).
7. 한자 전면 노출 금지(UI·일러스트 공통 기존 룰).
