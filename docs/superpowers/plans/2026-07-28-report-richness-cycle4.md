# Phase 1 — 어미·단정 정책 재설계 (3프롬프트 — "단정의 방향 전환" 명문화)

**목표:** "과장·단정 금지" 전역 규칙을 **결과 단정 금지**로 좁히고, 행동·성향 묘사에는 반대로 얼버무림을 금지한다.

### Task 1: 단정 3분법 규칙 신설 + 기존 금지 문구 교정

**Files:** Edit `lib/{marriage,wealth,career}-prompt.ts` (SYSTEM_RULES + OUTPUT_SCHEMA)

**변경 요지 (3파일 공통 이식):**
1. OUTPUT_SCHEMA의 "과장·단정 금지: 무조건·반드시·확실히·100%·절대·평생" 줄을 **"미래 결과에 대한 단정 금지"로 한정** 재작성: "미래의 성사·손익·성패를 단정하지 마라(무조건 된다/반드시 들어온다/평생 못 한다 류). **단, 이 금지는 미래 결과에만 적용된다 — 그 사람의 현재 행동·기질 묘사에는 단정형을 써라.**"
2. 절대 규칙 3-1의 "경향 + 방식 + 노력하면 나아지는 지점 형태로만" 프레임에 적용 범위 단서 추가: "(이 완곡 프레임은 **운의 결과를 말할 때**의 규칙이다. 성향·행동 묘사까지 '~한 편이야/~할 수 있어'로 뭉개면 리포트가 물러진다 — 행동 묘사는 아래 행동 단정 규칙을 따라라.)"
3. **행동 단정 규칙 신설**(냉철+재미 절 바로 아래, 3파일 공통): "★행동 단정 — 이 리포트의 소름 포인트: 사주 구조가 가리키는 **그 사람이 지금 실제로 하는 행동**은 확신을 갖고 단정형으로 그려라. - **회귀 — 결과 단정 누출 0**: 배치 전건 FORBIDDEN_PREDICTIONS 잔존 0 + 눈검수에서 "성사·손익 단정" 문장 0(가드 미커버 중간 강도 단정 — "이때 결혼하게 돼" 류 — 포함해서 눈으로 전수)
