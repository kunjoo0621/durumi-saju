# 사주보는 두루미 — SYSTEM_PROMPT (RESULT) v1.2

## 변경 사유 (vs v1.1)
- 7일 누적 115건 분석 데이터 결과: tier.title 비유의 60%가 자동차+자연 카테고리에 편중됨 (자동차 33%, 자연/기후 30%).
- 사용자 경험 측면에서 "결과가 항상 비슷한 느낌"이라는 운영자 관찰 + 외부 사용자 "어렵다" 피드백.
- 한자/사주 용어는 전문성 유지 차원에서 그대로. 비유 카테고리만 다양화.

## 핵심 변경

### 1. 비유 카테고리 풀 재정의 (6개 카테고리)
v1.1의 5개 카테고리(자연/물리/도시/디지털/스포츠)를 폐기하고 Z세대 직설 톤에 맞는 6개로 교체:

| 카테고리 | 입력 조건 | 어휘 풀 |
|---|---|---|
| 게임/디지털 | 모두 | 쿨타임, 콤보, 메타, 너프, 패치, 빌드, 스킬셋, 마나, 캐릭, 챔피언, 데미지, 방어구, 폭딜, 파티 |
| 머니/소비 | 모두 | 통장, 자동결제, 카드값, 월급, 가계부, 적금, 구독, 마이너스, 입금, 환급 |
| 직장/일 | **학생·취준 회피** | 야근, KPI, 분기 마감, 기획서, 회의, 결재, 평가, 성과, 리뷰 |
| 연애/관계 | **솔로 회피** | 썸, 손절, 환승, 잠수, 본 게임, 관심, 끌림, 미련 |
| 영화/드라마 | 모두 | 빌런, 주연, 조연, 시즌, 클라이맥스, 스핀오프, 결말, 캐릭터 점프 |
| 자동차 | **결과당 1회 이하** (백업) | 엔진, 브레이크, 핸들, 연료 |

폐기된 카테고리:
- 자연/기후 (장마·댐·안개·태풍 등) — 너무 wholesome
- 음식/요리 (셰프·재료·불 조절) — 너무 wholesome
- 스포츠/운동 (체급·기본기·페이스) — Z세대 공감 약함
- 음악 (박자·메인 멜로디) — 추상적

### 2. 카테고리 분산 강제 규칙 신설
- `tier.title`의 비유 카테고리와 종합 섹션(섹션 10) 첫 문단의 비유 카테고리는 **반드시 서로 다른 카테고리** 사용
- 자동차 비유는 결과당(11개 문장 = tier.title + 10 sections title) 합산 1회 이하

### 3. lib/analysis.ts 하드코딩 fallback 동기화
- L438 `THEME_HOOK_POOLS.natal[0]` — 자동차 → 게임 어휘
- L1173 mock fallback `tier.title` — "엔진은 강력한데 핸들이 좀 헐거운 스포츠카" → "데미지는 센데 빌드가 꼬인 챔피언"
- L1408 tier.title 예시 — 자동차 1개 → 6개 카테고리별 5~7개
- L1422 짧은 연타 예시 — 자동차 → 일상/머니
- L1657 비유형 section title 예시 — 자동차/물리 → 게임/머니/직장
- L1701 후킹 대비형 예시 — 자동차 → 게임/머니
- L1708 은유 사전 — 5개 → 6개 (위 표대로)
- L1845 중복 방지 예시 — 자동차 → 게임 어휘

## 변경하지 않은 것
- JSON 출력 형식, 길이 목표(섹션당 700~1200자), 팩폭 3회 규칙, 한자 병기 규칙, 반말 톤, 입력값 100% 반영 강제
- 사주 용어 자체 (편관·식상생재·관인상생 등) — 전문성 유지
- 종합 섹션 4문단 구조, 클로징 고정 문장
- 후킹 첫 문장 형식 옵션(직설/대비/질문/장면/선언/데이터)
