# 반려동물 궁합 — 표현 풀 종(species) 분리 (프롬프트 종 혼입 차단)

날짜: 2026-07-13
대상: `lib/pet-compat.ts` 인라인 프롬프트 (`PET_COMPAT_SYSTEM_PROMPT` const → `buildPetCompatSystemPrompt(species)` 함수) + `buildPetCompatUserInfo` 리마인더 + `lib/pet-compat-scoring.ts` `pickLabelText` 종 분기
LLM: Gemini API (`gemini-2.5-flash`, temp 0.85) — Claude API 아님
계획서: `docs/superpowers/plans/2026-07-13-pet-species-leak-prompt.md`

## 왜 바꿨나

강아지(두부, 시츄) 실측 결과의 `petVerdict`에 **고양이 전용 행동 "꾹꾹이"**(앞발 꾹꾹)가 섞여 나옴.
엔진은 `pet.species: "dog"`를 정확히 넘기는데 LLM이 프롬프트에 놓인 고양이 어휘를 골라 씀.

근본 원인: 시스템 프롬프트의 `[참고 표현 풀]`이 **종 무관 단일 리스트**였음.
- 154줄 권력(묘르신·냥느님), 158줄 모순 짚기(골골송·식빵), 159줄 신조어(꾹꾹이·냥줍·묘연 …
  + 개 전용 댕댕이·시고르자브종 혼재)
- 137·138줄 viral 예시, 197줄 D라벨 예("묘연"), 199줄 권력 코드(묘르신), 310줄 외모 디스 예외(뚱냥이)
  전부 고양이 편향
- 162~165줄 `[종별 톤 분리]`는 아키타입만 갈랐고 **어휘 풀은 안 가름** → temp 0.85에서 누출 구조적

즉 기존에 이미 "종별 톤 분리" *지시*가 있었는데도 샜다 = 지시-only 방식의 실패 사례.

## 무엇을 바꿨나

접근 ③ (컨텍스트 제거 + 명시 금지 이중 방어):

1. **`PET_COMPAT_SYSTEM_PROMPT` const → `buildPetCompatSystemPrompt(species)` 함수**.
   종 민감 지점을 `${isDog ? DOG : CAT}` 조건부로 주입 — 반대 종 어휘를 컨텍스트에서 원천 제거:
   - viral 패턴 6·7 (호칭 격상·방언 예시)
   - 참고 표현 풀 (권력·모순 짚기·신조어) → [공용] + [해당 종]만
   - D 라벨 예시 / ruler 권력 코드 / 외모 디스 예외 / 시뮬 scene 예시
2. **hard guard 신설** ([종별 톤 분리] 아래): "이 펫은 {강아지|고양이}다. 반대 종 전용 행동·용어 금지" +
   금지 단어 명시 리스트(꾹꾹이·골골송·식빵 … / 댕댕이·산책 …). pretraining 유래 누출까지 차단.
3. **userInfo `종:` 줄 아래 리마인더 1줄** (recency 강화).
4. **`pickLabelText`에 species 인자 추가** — D등급 라벨 "묘연"(고양이)이 강아지에도 박히던 것을
   `species === "cat" ? "묘연" : "인연"`으로 분기. (서버 라벨이 LLM 출력을 덮어쓰므로 프롬프트만으론 못 막음)
5. (운영자 승인) S등급 라벨 `"네가 더 매달리는 운명의 인연"` → `"팔자의 인연"` — 프롬프트가
   "운명" 금지인데 서버 라벨이 위반하던 톤 불일치 교정.

## 어휘 분류 기준

- 고양이 전용: 꾹꾹이·골골송·식빵(자세)·냥줍·묘연·묘르신·냥느님·개냥이·뚱냥이·아깽이·하악질·그루밍·츄르·캣타워
- 개 전용: 댕댕이·똥강아지·시고르자브종·뽀시래기·짱절미·산책(장면)·꼬리 프로펠러
- 공용(둘 다 OK): 집사·만렙·1순위·폐하·집안 실세·츤데레·밥시계·생존형 협상·영업·푸시 알림·우다다(줌미는 양종 공통)

## 검증

dev-test 개 3·고양이 3케이스 → 전 텍스트 필드를 반대 종 어휘 배열과 자동 그렙, 교차종 매칭 0 확인.
한자 병기 ≤3·"운명" 0 회귀 없음.

## 회귀 불변 (안 건드림)

톤 규칙(귀엽게 놀리기·의료/인격/단절/비교 금지), 12지 연주 기준 룰, 표현 중복 금지,
한자 병기 상한 3, 출력 JSON 스키마, 점수·등급 서버 결정 원칙, `PET_COMPAT_SCORING_VERSION`(v4 유지 — 점수 로직 무변경).
