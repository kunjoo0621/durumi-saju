# 사주보는 두루미 — SYSTEM_PROMPT (RESULT) v1.3

## 변경 사유 (vs v1.2)
운영자 관찰 + 실측: 결과 화면 **등급 아래 한 줄(tier.title)** 이 두 가지 문제.
1. **이해 난이도**: 게임 인사이드 슬랭(딜·마나·쿨타임·만렙·유리대포·빌드)이 주 사용자층(2030 여성, 게임 비유저 다수)에게 안 와닿음. v1.2가 "게임/디지털" 풀을 전 연령 1순위로 둔 부작용.
2. **등급-톤 불일치**: 모든 등급이 "강점 BUT 치명적 약점" 한 구조로 생성돼, SS·S(상위권)인데도 "방어구 안 입고 위태로운", "속은 타는" 식으로 끝나 **고등급인데 기분 나쁨**. 실제 샘플: 내부 S 90 → "공격력은 만렙인데 방어구 안 입고 필드 나가는 딜러".

## 핵심 변경 (tier.title 규칙 전면 교체)
v1.2의 "연령별 비유 풀(게임/머니/직장/연애/드라마 · 생활/자연/가전)" 나열을 폐기하고, 6개 규칙으로 재정의:

1. **맞춤형(범용 금지)**: 강점=5분야 최고점 분야, 약점=최저점 분야에서 추출. 범용 제목 실패 처리. (재물→돈/직업→회사/애정→연애/건강→몸/관계→사람)
2. **한 제목 = 한 비유 세계**: 강점·약점·끝 명사를 같은 세계로 통일(세계 혼합 금지) → v1.2 산출의 어색함(연애+게임+드라마 혼합) 해결.
3. **끝맺음**: "~사주/~구조/~결" 종결 금지 → 세계별 "정체성 명사"로 종결(부자/에이스/만년 인턴/순삭러/시한부/럭키비키 등). 종결 단조로움 제거.
4. **등급별 강도 그라데이션(★ 신규 핵심)** — 내부 등급 기준(화면: S→SS, A→S, B→A, C→B, D→C):
   | 내부 | 화면 | 분포(v11) | 톤 |
   |---|---|---|---|
   | S·A | SS·S | ~3%·~10% | 약점 0, 강점만 (멋지게) |
   | B | A | ~27% | 강점 우세 + 애교 흠 |
   | C | B | ~54% 최다 | 강점·약점 반반 (균형) |
   | D | C | ~7% | 약점 정면 (팩폭, 가장 세게) |
   → 다수(화면 A·B)에게 팩폭 금지, 팩폭은 최하위(화면 C)만. 상위(화면 SS·S)는 약점 절 자체 제거.
5. **나이대 분기 갱신**: 49↓(2030 메인)은 돈·회사·연애·드라마 + 2030 밈(럭키비키·갓생·무지출챌린지·텅장·효율충·프로~러)으로, 단 게임 인사이드 슬랭 금지. 50↑은 살림·자연·가전 세계로 동일 강도 위트.
6. **밈 변주·1개 제한**: 예시 복붙 금지, 한 제목당 밈 1개.
