# 사주보는 두루미 — SYSTEM_PROMPT (RESULT) v1.4

## 변경 사유 (vs v1.3)
v1.3 배포 직후 실측: 신규 분석 첫 건(내부 S 89 = 화면 SS)에서
> "일머리는 만렙인데 통장에 구멍 난 효율충"
- "효율충"(v1.3 신규어)은 반영됐으나 **"만렙"(게임 슬랭) 누출** + **상위권인데 약점 절 포함**.

원인: v1.3는 tier.title 규칙 블록만 바꾸고, **같은 프롬프트의 다른 곳에 게임 슬랭 모범예시·은유 사전이 그대로 남아** 모델이 거기서 베껴옴. 프롬프트가 자기모순(새 규칙 ↔ 옛 예시) 상태였음.

## 핵심 변경 — 게임 슬랭 전수 제거 + 톤 통일
v1.3에서 못 지운 게임 슬랭 예시·풀을 전부 정리 (총 11곳):
- `MOCK_DATA.title` "데미지는 센데 빌드가 꼬인 챔피언" → "사람도 일도 술술 풀리는 타고난 에이스"
- `THEME_HOOK_POOLS.natal[0]` "스킬셋…빌드…" → 비게임 문장
- 섹션 title 비유형 예시 "쿨타임 안 도는 폭딜기" → "월급 따박따박인데 통장은 텅장" 등
- 후킹 대비형 예 "데미지는 센데 마나가 비었어" → 제거
- **은유 사전의 "게임/디지털" 풀(쿨타임·마나·캐릭·챔피언·딜·만렙…) 폐기** → "2030 밈/일상" 풀(텅장·플렉스·갓생·무지출챌린지·효율충·프로~러)로 교체, 게임 인사이드 슬랭 **전 연령 금지** 명시
- 분산 규칙 예시 "유리대포·폭딜기" → "텅장·만년 인턴"으로, ✓통과 예 tier.title도 비게임으로
- "tier.title이 게임이면…" → "비유 세계 겹치지 않게"로 일반화
- 섹션 규칙(1736)·강등 규칙(1823)에 게임 슬랭 전 연령 금지 못박음

## 핵심 메시지(일관성)
- 게임 인사이드 슬랭(쿨타임·마나·캐릭·챔피언·딜·만렙·폭딜·빌드·너프 등 비게이머 미상용어)은 **전 연령·tier.title·섹션 전부 금지**. 단어 예시·은유 사전·모범예시 어디에도 남기지 않음.
- 위트는 2030 밈/일상·돈·회사·연애·드라마로, 50+는 살림·자연·가전으로.
- tier.title 등급 강도(S·A 약점0 / B 우세 / C 반반 / D 팩폭)는 v1.3 그대로.
