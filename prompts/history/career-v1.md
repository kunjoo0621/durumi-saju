- 파일: `lib/career-prompt.ts` — `SYSTEM_RULES` + `OUTPUT_SCHEMA` (신규, v1)
- 설계 근거: `docs/plans/2026-07-20-career-luck-design.md` §Phase 2 (grade+prompt)
- 패턴 원본: `lib/wealth-prompt.ts`(main, 재물운 최신판) — 구조(사실 블록 빌더 + SYSTEM_RULES +

  안전장치를 커리어 도메인으로 재작성했다.

## 왜 이 프롬프트가 이렇게 생겼는가 (설계 의도)

커리어운의 포지셔닝은 "어떤 그릇으로 어느 길(조직/독립/전문/자격)을 가야 하는가"다. 재물운(재성 축, 돈
축적)과 **질문 자체가 다르다**. 개인사주 직장운 섹션이 이미 관성·인성 구성 요소를 노출했으므로, 이
프롬프트의 값어치는 세 곳에서만 나온다 — 관성의 위치·유형 해상도(궁위), 책임·자리를 담는 그릇(신강신약
×관성 4상한), 그리고 **타이밍**(관성·인성·식상 투출 세운 + 관성 대운). 재물운과 동일하게 [절대 규칙 2]에
"타이밍이 핵심 값어치"를 박고 상황별 3블록에 `timingFlow`를 필수 배치했다.

## 재물운과의 경계 (중복 방지 — 값어치의 핵심)

재물운은 "돈이 붙나"(재성·그릇·손재), 커리어운은 "네 기질이 조직형이냐 독립형이냐"(관·식상 배치)다.
[이 검사의 위치] + [절대 규칙 2]에 "돈 얘기로 새지 말고 길·기질·자리만 다뤄라 — 돈이 나올 자리엔 역할·
자리·인정·전문성을 넣어라"를 명문화했다. 두 리포트가 "사업" 얘기를 해도 재물운='사업하면 돈 붙나',
커리어운='조직형이냐 독립형이냐'로 갈린다.

## 안전장치 8종 (재물운 9종 미러 + 커리어 치환) — 위치

1. **입력 사실 외 명리값 생성 금지** — 괴강·백호·양인·12운성·공망·원진·삼재 fabrication 금지(3a48370
   상속). ★커리어 특별 경고 추가: **괴강·장성·학당은 개인사주 채점엔 있지만 이 facts 블록엔 없다** —
   "괴강이라 리더십" 류(LLM이 커리어에서 가장 끌어오고 싶어 하는 함정) 절대 금지. + 수치/나이/한자/그릇
   용어명 노출 금지 + `{{CURRENT_YEAR}}`/`{{PREV_YEAR}}` 치환(연도 썩음 방지).
2. **차별화 + 타이밍 핵심 값어치** + 재물운 경계 명문화(돈 얘기 금지).
3. **숙명론 금지 커리어판** — "승진 못할 팔자/조직생활 못한다/백수 팔자/사업하면 망한다" 금지 +
   **관다신약 재해석**(감당·페이스가 관건, "번아웃 온다" 단정 금지) + **상관견관 재해석**(말을 문서로,
   반박을 제안으로 — 15b41fc 여명 안전 재해석 클래스) + **무관 재해석**(직함보다 실력이 명함인 자유형) +
   신약관소 구별.
4. **타이밍 프레임** — 승진·합격·이직 성사 단정 금지, 실패·해고 단정 금지. 트리거 이름 노출 금지.
5. **인생 중대 결정 단정 금지**(재무자문의 커리어판) — 퇴사·이직·창업 실행 단정("지금 그만둬라") 금지,
   특정 회사·시험 합격 보장 금지, 특정 직업 못박기 금지(직업 '군'의 결까지만 허용).
6. **상황-구조 불일치 짚기**(서버 결정론 감지 — `detectSituationStructureGap`, false negative 방지).
7. **직업 상태 grounding** — situation 1순위, employmentStatus는 예시 톤 보조(이중 grounding).
8. **상관견관=예이면 "조직운 완벽" 순수 긍정 금지**(wealth 겁재 탈재 규칙 8 미러) — gradeHeadline/
   careerGripDiagnosis/현직 성장 riskAndPace에서 마찰 지점을 강점 전환으로 풀되 순수 긍정 금지.

## 출력 스키마 (9키)

`teaserSummary / gradeHeadline(35자) / gwanseongDiagnosis / careerGripDiagnosis / workStyle / riskAndPace /
timingFlow / advice[{text, tag:"[근거:...]"}] / yearlyCta`. 상황(situation) 4분법으로 workStyle·riskAndPace·
timingFlow 3블록 분기(진로 탐색 / 현직 성장 / 이직 고민 / 독립·사업).

## 후속(Phase 3에서 이중 방어)

프롬프트 지시만으로 안 새는 걸 전제하지 않는다 — `lib/career-postprocess.ts`가 숙명론·실행 단정·한자·
수치·그릇 용어·괴강 fabrication을 결정론으로 한 번 더 컷하고, `career-prompt.test.ts`의 "좋은 문장 예시가
가드에 안 걸린다" 3-layer 정합 테스트로 프롬프트↔가드 정합을 검증한다(Phase 3).
