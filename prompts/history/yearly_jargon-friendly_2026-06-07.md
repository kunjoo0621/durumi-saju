# 올해의 운세 — 명리 용어 친화어 변환 (v1.0 → v1.1)

날짜: 2026-06-07
대상: `lib/yearly-prompt.ts` (인라인 const `YEARLY_SYSTEM_PROMPT`)
※ `prompts/durumi_YEARLY_SYSTEM_PROMPT_v1.0.md` 파일은 **미사용(stale)** — 코드는 인라인 const를 씀.

## 왜 바꿨나

투데이/올해 결과를 5명(20·30·40·50대 / 남녀 / 솔로·기혼 / 직장인·취준·자영업·은퇴·시간모름,
등급 B·C 혼합) 실제 Gemini 생성해 측정:

| | 한자누출 | 사주용어 밀도(결과당) |
|---|---|---|
| 투데이 (v1.7) | 0/0/0/0/0 | 0·1·5·1·1 (사실상 "일진" 한 단어뿐) |
| 올해운세 (v1.0) | 0/0/0/0/0 | **46·43·62·50·46** |

한자는 둘 다 0(프롬프트 차단 확실). 그러나 **올해운세는 차트 무관하게 매번 십성·12운성·천간/지지
음역·합충 메커니즘·음역 달이 40~60개씩 본문에 박혀** 명리 모르는 일반 유저 가독성을 깎았다.
근본 원인은 v1.0 프롬프트가 *오히려 jargon을 의무화*했다는 것:
- "십성·신살 의인화 ★섹션마다 2회 이상" → 바른 이름(정재/겁재…) 강제
- 세운 활용·납음 의무·시그니처 예시가 전부 천간/지지/12운성/합충 raw 용어를 모델링

핵심 통찰(투데이 v1.7과 동일): 본문은 명리학 모르는 사람이 읽는다. **재미 엔진(십성 의인화 한 줄,
"통장에 빨대 꽂는 겁재")은 살리되, "메커니즘 강의"("임수가 병화와 충돌", "정재가 사지에", "5월 갑오월")
만 죽여야 한다.** 투데이처럼 음역어 전면 금지로 가면 의인화 농담까지 죽으므로 차등 적용.

## 무엇을 바꿨나 (모두 인라인 const 본문 룰)

1. **신규 블록 `[명리 용어 친화어 변환 ★★★ v1.1]`** ([개인사주와의 톤 분리] 다음에 삽입):
   - A. 본문 출력 절대 금지 — 천간/지지 음역, 12운성(장생~절+"~지" 형), 합충 메커니즘 노출,
     음역 달(갑오월/병신달…→ "N월" 숫자만), 위치용어(일간·일지·세운·대운·납음).
   - B. 십성·신살은 캐릭터로 유지하되 "정체를 그림으로" — 바른 이름만 던지기 금지, 첫 등장 친화 꼬리표.
   - C. 친화어 변환 가이드(내부 추론용): 천간/지지→오행+계절감, 12운성→흐름 비유, 합충→관계 비유.
   - D. **이번 검증에서 실제로 나온 나쁜 예 3개 → 고친 예** 박아넣음(임수/병화 충돌, 갑오월, 건록지).
2. 의인화 의무 라인 패치: "정재가 손짓" → "통장 빠는 얌체 기운이 손짓" + 메커니즘 0회 명시.
3. 시그니처/톤 규칙/충합없음 예시의 raw 천간(임수)·raw 십성(정재/겁재) → 전부 친화어로 교체.

## 안 바꾼 것 / 주의
- 점수·등급·길이·톤(친한 형)·솔직 직설·7:3·납음 비유 등 기존 골격 전부 유지.
- SCORING_VERSION 불변(서버 점수 로직 무변경, 프롬프트는 캐시 키 아님 → 기존 캐시 결과 유지, 신규만 v1.1).
- 투데이는 손 안 댐(이미 깨끗). 투데이 잔존 과제="구조 반복(💸가 매번 같은 틀)"은 별건.
