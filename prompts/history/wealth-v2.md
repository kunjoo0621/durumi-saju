## v1 → v2 변경점

### 1. 재성 궁위(宮位) 해석 라인 추가 (facts→프롬프트, 결정론)
`buildFactBlock`에 "재성 궁위 해석" 라인 신설 — 재성이 앉은 기둥을 인생 국면으로 번역
(`formatJaeseongGungwi`, 서버 결정값):
- 년주 = 초년·집안 뿌리 국면 / 월주 = 사회활동기(직장·벌이 무대) / 일지 = 중년·배우자와 살림 /
  시주 = 말년·자녀·노후.

절대 규칙 2(차별화)에 "궁위 활용" 지시 추가 — jaeseongDiagnosis에서 "어느 인생 국면의 돈인지"를
반드시 짚게 함. LLM은 국면 해석만, 없는 기둥/국면 생성 금지(숫자·새 판정 생성 금지 원칙 유지).

### 2. 긍정 예시 블록 추가 (금지 위주 → 목표 해상도 제시)
블록 구조 앞에 `[좋은 문장 예시]` 블록 신설 — 재성 진단(위치+방식)·그릇 진단(구조+대응)·타이밍
(연도+행동) 3종의 목표 해상도 예시. 예시 문장은 wealth-postprocess 금지 정규식을 통과함을
테스트(`lib/wealth-prompt.test.ts`)로 고정.

### 3. 어투 반말 100% 통일 (내용 스타일 교정)
SYSTEM_RULES는 "반말 100%·존댓말 금지"(163~164행)를 규정하는데, v1의 **허용 예시 문장들이
존댓말**("구조예요·좋아요·핵심이에요·시기예요")로 규칙과 모순돼 있었다 → 전부 반말로 교정
(191~193, 208, 221~223, 235, 241~243행). 금지 예시(봅니다/합니다/투자하세요)는 부정 예시라 유지.
두루미 브랜드 목소리(직설적인 친한 친구) 일관성 확보.
